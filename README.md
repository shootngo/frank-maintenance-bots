## Enable GitHub Pages (one-time)

Deploy workflow is ready but GitHub requires a one-time toggle:

1. Open https://github.com/shootngo/frank-maintenance-bots/settings/pages
2. Under **Build and deployment** → **Source**, choose **GitHub Actions**
3. Re-run the "Deploy GitHub Pages" workflow (Actions tab → Run workflow), or push any commit
